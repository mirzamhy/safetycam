Pelanggaran

    APD terpakai

      Turunkan untuk menangkap objek kecil, naikkan untuk mengurangi deteksi keliru.

      Yang dicek pada setiap pekerja

      Model dilatih untuk dua hal: mengenali APD yang dipakai, dan mengenali bagian tubuh yang seharusnya terlindungi tapi tidak.

      APD terpakai

      • Helm
      • Rompi
      • Sarung tangan
      • Sepatu safety
      • Kacamata

      Ditandai pelanggaran

      • Tanpa helm
      • Tanpa sarung tangan
      • Tanpa sepatu safety
      • Tanpa kacamata

      Rompi tidak punya label pelanggaran di dataset ini, jadi pekerja tanpa rompi belum bisa ditandai.

      Dari dataset ke browser

      1. 01

        Dataset Construction-PPE

        1.416 foto lokasi kerja berlabel kotak untuk 11 kelas, dari Ultralytics.

      2. 02

        Training YOLO11n

        Model deteksi terkecil di keluarga YOLO11, dipilih supaya cukup ringan untuk laptop dan ponsel.

      3. 03

        Export ke ONNX

        Input 640×640, output 15 × 8.400 kandidat kotak. Penyaringan kotak (NMS) dikerjakan di JavaScript.

      4. 04

        Inferensi di browser

        onnxruntime-web memakai WebGPU bila tersedia, WASM bila tidak. Gambar tidak pernah keluar dari perangkat.

      Akurasi model

      Diukur pada data uji yang tidak dipakai saat training. mAP50 menghitung tebakan benar bila kotaknya tumpang tindih minimal 50% dengan label asli.

      mAP50, semua kelas

      Angka akurasi belum tersedia. Jalankan python evaluate.py lalu python export.py setelah training penuh, dan tabelnya muncul di sini.
